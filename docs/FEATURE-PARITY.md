# خريطة نقل ميزات Magic RDR (PC → Android)

مصدر القائمة: بنية مشروع Magic-RDR 1.3.10 الأصلي (أسماء الملفات والنماذج وأحجام الأكواد). **لم أقرأ كل ملف بعمق**؛
التقدير يقوم على الأسماء والحجم، فراجع كل بند قبل البدء به.

التصنيف: **A** منطق صرف قابل للنقل · **B** يحتاج بديلاً للواجهة/الرسوم · **C** يعتمد على ويندوز أو مكتبة أصلية.

## ترتيب الأولويات المقترح (للترجمة أولاً)

1. **سلامة الأرشيف**: فحص بعد الحفظ (مقارنة محتوى كل ملف غير معدّل بين الأصل والناتج) + اختبار حقيقي لاستخراج/استبدال/حفظ على نسخة.
2. **عارض Hex + خصائص العنصر**: الـ Hex منفّذ؛ تبقى خصائص العنصر.
3. **عارض/محرر النصوص** (منفّذ) ← **فكّ ضغط الموارد (Switch)** (منفّذ) ← **قراءة جداول النصوص** (منفّذة) ← **كتابة جداول النصوص** (منفّذة، تُجرَّب الآن): هذا مسار حقن الترجمة الكامل.
4. بعد ذلك: إضافة/حذف، تسمية يدوية، الصور، السكربتات، الحفظ، ثم النماذج والصوت (الأصعب).

## قواعد "تعريف الإنجاز" لكل ميزة منقولة

- محلل في Core + اختبار بوحدات بيانات اصطناعية يمرّ على CI.
- لا مكتبات ويندوز، لا تحميل كامل للملفات الكبيرة.
- تُجرَّب على الهاتف بأرشيف **منسوخ**، وتُقارَن النتيجة بنسخة PC قبل اعتمادها.

## حفظ الجلسة (منفّذ)

التطبيق يحفظ داخل مخزنه الخاص: نسخة الأرشيف العاملة، والتعديلات غير المحفوظة، والمجلد الحالي، والعنصر المحدد، ونص التصفية، وموضع التمرير.
عند فتح التطبيق من جديد يعيد كل ذلك تلقائياً. زر **Close** يغلق الأرشيف ويحذف النسخة المحفوظة لتحرير المساحة.

## أسماء الملفات
- الأرشيفات (Switch) قد تخزّن أسماء الملفات داخلها: التطبيق يقرأها عند الفتح ويقبل كل اسم **فقط إذا طابق الـ hash**.
- ما لم يُوجد داخل الأرشيف يأتي من `names.txt` (يُضمَّن عبر المستودع) أو من زر Import names أو Find names.

## العربية في جداول النصوص (منفّذ، يحتاج تجربة على اللعبة)
اللعبة ترسم النص من اليسار لليمين بلا تشكيل، فالعربية تُخزَّن **بصرياً**: أشكال العرض (`U+FE70–FEFF`، `U+FB50–FDFF`) بترتيب معكوس.
`ArabicVisualCodec` (في Core) يحوّل بين الشكلين:
- **Decode** (للعرض والتصدير): يعكس الترتيب ويعيد الحروف الأساسية (`U+0600–06FF`) ويفكّ لام-ألف. النص الذي لا يحوي أشكال عرض يُترك كما هو.
- **Encode** (عند Apply entry / Apply table / Import): يشكّل الحروف (ابتدائي/وسطي/نهائي/منفصل + لام-ألف) ثم يعكس الترتيب.
- الوسوم `<red>` ورموز الألوان `~r~` وعناصر `%s` و`{0}` و`\n` والأرقام والكلمات اللاتينية وحدات لا تُعكس، والأقواس تُقلب، وكل سطر يُعالج وحده.
- مفتاح **Arabic Visual Fix** في لوحة Table (مفعّل افتراضياً ويُفعَّل تلقائياً عند اكتشاف أشكال العرض).
- الإدخالات التي لم تُعدَّل تبقى بايتاتها الأصلية كما هي (لا إعادة ترميز)، وزر Revert يعيد البايتات الأصلية.

## التحديد المتعدد والاستخراج/الاستبدال الدفعي (منفّذ)
- زر **Multi-select** يظهر مربع اختيار على كل ملف (والنقر على الصف يبدّل الاختيار)، مع **Select All / Select None** وعدّاد `X selected`. الاختيار يبقى عند تغيير المجلد أو التصفية، ويُمسح عند فتح أرشيف آخر أو حفظ الأرشيف.
- **Extract** مع اختيار متعدد: يستخرج كل الملفات المحددة (تقدّم + إلغاء) في ملف ZIP واحد، وتُسمّى بالاسم المعروف أو بالـ hash (`0x00FEB5CC`)، وتُضاف لاحقة `_2` عند تكرار الاسم.
- **Replace** مع اختيار متعدد: على الملفات المحددة، أو على كل ملفات المجلد الحالي إن لم يُحدَّد شيء. المصدر إما عدة ملفات (`PickMultipleAsync`) أو ملف ZIP. المطابقة بالاسم ثم بالاسم بلا امتداد ثم بالـ hash (`0x…`)، وتظهر رسالة تأكيد مثل `Matched 24 of 25 selected entries. Replace all?`. الحالات الملتبسة (ملفان يصلحان لعنصر أو عنصران لملف) تُتخطّى وتُذكر.
