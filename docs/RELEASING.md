# التوقيع والإصدارات (Release)

## ما الذي يسمح بالتحديث فوق النسخة الموجودة
يقبل أندرويد التحديث المباشر فقط إذا تحقق الشرط الثلاثي:

1. نفس **الهوية** `ApplicationId = com.magicrdr.mobile` (لا تغيّره أبداً).
2. نفس **مفتاح التوقيع** (الـ keystore الدائم).
3. **versionCode أكبر** من المثبّت.

## كيف يُحسب الإصدار في CI
- `versionCode` = عدد الدقائق منذ 2026‑01‑01 UTC (يرتفع دائماً، ولا يتأثر بإعادة إنشاء الـ workflow أو إعادة التشغيل).
- `versionName` = `APP_VERSION_BASE` (في أعلى `main.yml`، حالياً `1.0`) + `.` + رقم التشغيل. مثال: `1.0.7`.
- لرفع الإصدار الظاهر للمستخدم غيّر `APP_VERSION_BASE` فقط (مثلاً `1.1`).

## إنشاء المفتاح الدائم (مرة واحدة فقط)
1. Settings ← Secrets and variables ← Actions ← **New repository secret**:
   الاسم `ANDROID_KEYSTORE_PASSWORD`، والقيمة كلمة مرور قوية (12 حرفاً فأكثر). **سجّلها خارج GitHub.**
2. Actions ← **Create signing key (run once)** ← Run workflow ← اكتب `CREATE`.
3. بعد النجاح: افتح التشغيل ← Artifacts ← نزّل `signing-key-backup` (صالح يوماً واحداً).
4. فكّ الضغط: ستجد `magicrdr-release.keystore` و`keystore.base64.txt`.
   - احفظ `magicrdr-release.keystore` في مكانين آمنين (مع كلمة المرور).
   - افتح `keystore.base64.txt`، انسخ كل محتواه، وأنشئ secret جديداً باسم `ANDROID_KEYSTORE_BASE64`.
5. شغّل البناء. في Summary يجب أن يظهر `Signing: permanent release key` وبصمة الشهادة، مع `v3 = True`.
   (قد يظهر `v2 = False` وهذا طبيعي: الحد الأدنى للنظام 29، وapksigner يكتفي بتوقيع v3 لأنه يغطي أندرويد 9 فأحدث.)

> إذا فقدتَ المفتاح أو كلمة مرور: لن يقبل أندرويد أي تحديث فوق النسخة المثبّتة، وسيلزم حذفها وتثبيت الجديدة.
> لا ترفع الـ keystore إلى المستودع (`.gitignore` يمنع ذلك).

## ما الذي يضمنه التوقيع وما الذي لا يضمنه
- يضمن: هوية ثابتة للمطوّر، وسلامة الملف (أي تعديل بعد التوقيع يُبطله)، وإمكان التحديث المباشر.
- لا يضمن: أن يعتبره أندرويد أو Play Protect "موثوقاً". الشهادة الذاتية لا تمنح سمعة؛ سيظهر تحذير "مصدر غير معروف"
  عند التثبيت اليدوي. الثقة الكاملة تحتاج النشر عبر Google Play.

## الانتقال الأول (مرة واحدة)
النسخة المثبّتة الآن موقّعة بمفتاح اختبار مؤقت تغيّر في كل بناء. أول بناء بالمفتاح الدائم **يتطلب حذف النسخة الحالية** ثم التثبيت.
بعدها تُثبَّت كل التحديثات فوقها مباشرة.
